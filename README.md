# Simple Interest Calculator

This project calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Annual rate of interest
- Time period in years

## Output
- Simple interest calculated using the formula

## Example
Principal = 1000  
Rate = 5  
Time = 2 years  

Simple Interest = (1000 × 5 × 2) / 100 = 100# simple-interest-calculator
